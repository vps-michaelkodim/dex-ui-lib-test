# Claude-Skills

Skills, mit denen Claude (Cowork, Claude Code, claude.ai) die Library richtig benutzt.

| Skill                                     | Wofür                                                                          |
| ----------------------------------------- | ------------------------------------------------------------------------------ |
| [`dextinity-ui`](./dextinity-ui/SKILL.md) | UI, Screens, Prototypen und Komponenten für Dextinity mit dieser Library bauen |

## Installieren

- **claude.ai / Cowork:** in den Claude-Einstellungen bei den Skills den Ordner `dextinity-ui`
  (als ZIP) hochladen. Oder Claude bitten: „Speicher den Skill aus `ai/skills/dextinity-ui/SKILL.md`“.
- **Claude Code (nur dieses Repo):** Ordner nach `.claude/skills/dextinity-ui/` kopieren.

Änderungen am Skill hier im Repo machen (PR), dann neu installieren.
